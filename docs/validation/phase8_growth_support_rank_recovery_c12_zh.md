# Phase 8 C12：支持秩约束小脑与踢后恢复闭环报告

日期：2026-08-08
范围：SIM_ONLY，MuJoCo CPU 物理；4×RTX A6000 用于并行隔离实验进程与 EGL 渲染，不声称 GPU 物理加速，不涉及真实机器人。

## 1. 结论先行

C12 没有把单个 seed 0 的成功继续包装成“已泛化”。本轮首先复现了 C11 在 seeds 1–4 上的失败，然后审计 29 个新的/已有 SONIC 助跑方案，确认问题的主要来源是：SONIC `planner_seed` 生成的是不同全身动作计划，不是普通环境噪声；同一套触球动作不能盲目套在所有计划上。

本轮取得了三个可复现的进展：

1. 找到并优化了第二个安全、连续的本体状态技能岛（seed 32）。其 5 m 左上高目标误差由 `0.9231 m` 降至 `0.4811 m`，改善 `47.9%`；横向误差仅 `2.16 cm`，剩余误差几乎全部来自高度不足。
2. 将弹道 actor-critic 加固为“支持秩约束”版本：只有至少出现 3 个独立取值、且确实增加回归设计矩阵秩的关节维度才能更新；缺乏独立证据的关节冻结在最佳安全锚点。这是 Stability–Plasticity Dilemma 的一个工程化解法：有证据时保持可塑性，无证据时优先保持稳定。
3. 新增踢后恢复阻尼和物理轨迹指标。seed 32 在不改变球路的前提下，恢复期 29 关节速度 RMS 均值降低 `35.1%`，骨盆平均平移速度降低 `24.9%`，稳定耗时缩短 `15.7%`；无后退、无跌倒、无关节/力矩越界。

仍需明确：两个最终射门的总误差分别为 `0.4165 m` 和 `0.4811 m`，均未达到 `0.16 m` 精准晋级门槛；冻结策略在全新 seeds 33–36 的密封 holdout 上也被五项门控拒绝。因此证据和视频保持 `REJECTED / SIM_ONLY`，没有授权晋级或真实硬件运行。

## 2. 为什么 C11 的多 seed 结果失败

C11 在 seed 0 上得到一套很好的弹道残差，但原动作在 seeds 1–4 上只有低平球或失败，并出现连续性、跌倒和关节边界问题。C12 又复验了旧的相位路由和 `P180/P195/P205/P220` 相位网格，结论是：仅改变开踢相位无法修复不合适的助跑末端全身状态。

关键认知修正如下：

- `planner_seed` 决定 SONIC 全身运动参考，改变的是助跑、刹停和交接时的完整本体状态。
- 旧路由只使用骨盆姿态、位置和关节速度 RMS 共 6 个聚合特征，无法区分完整 29 关节构型与速度。
- 29 个方案池中，23 个满足硬安全、16 个满足连续性、18 个越过球门平面，但只有 seed 0 的过门高度达到 `0.65 m`。把此前 seeds 1–4 的失败复验计入后，33 个执行中也只有 1 个满足该高度条件。
- 因而正确方向不是把随机计划都当作可执行动作，而是形成“本体状态 → 适用触球技能/拒绝”的技能记忆，并为新的状态单独成长出技能岛。

完整本体向量（骨盆位姿、29 关节位置、29 关节速度）显示 seed 32 是 seed 0 最近的未开发状态，稳健尺度距离约 `2.794`；下一近邻已超过 `4.9`。因此本轮选择 seed 32 做第二技能岛，而不是继续无目的随机扫描。

## 3. seed 32 的数据驱动成长过程

### 3.1 六关节残差消融

弹道动作顺序为：右髋俯仰、右髋横滚、右髋偏航、右膝、右踝俯仰、右踝横滚。

初始安全动作在 seed 32 上的过门点约为 `(y=1.031, z=0.427) m`，目标为 `(1.0, 1.35) m`，误差 `0.9231 m`。

严格回放显示：

- 踝俯仰 `+0.25 rad` 能稳定增加球的垂直速度。
- 髋俯仰沿负方向从 `-0.02` 扫到 `-0.25 rad` 时，误差持续下降，且安全、连续性和饱和步数基本不变。
- 膝残差在 `0 rad` 附近最优；继续伸膝或屈膝都会同时破坏高度或横向落点。
- 最佳关节组合为 `[-0.25, -0.010683, -0.06, 0.0, 0.25, 0.030475] rad`。

### 3.2 触球时间相位

同一动作在接触中心帧 `248/252/256/260/264` 上呈现明显窄窗口：

| 接触中心帧 | 过门高度 | 总误差 | 安全/连续 |
|---:|---:|---:|:---:|
| 248 | 0.215 m | 1.149 m | 是 |
| 252 | **0.869 m** | **0.481 m** | 是 |
| 256 | 0.804 m | 0.546 m | 是 |
| 260 | 0.214 m | 1.137 m | 是 |
| 264 | 0.114 m | 1.236 m | 是 |

这说明小脑动作不能只有“发多大力”，还要学习“在什么本体状态、什么相位发力”。相位 252 的最终过门点为 `(6.0, 0.97836, 0.86936) m`，横向已经接近目标，下一阶段主要应学习触球高度和垂直冲量，而不是继续增加横向偏置。

## 4. actor-critic 的 Stability–Plasticity 加固

原二次 critic 在 6 维动作中即使某些关节只有 1–2 个取值，仍会受相关性影响产生虚假梯度。例如髋横滚、髋偏航、膝和踝横滚曾经一起变化，模型无法判断是哪一维真正有效，却可能同时更新它们。

新版本执行三层约束：

1. 每个可塑维度至少需要 3 个独立动作值，才能估计局部线性与曲率。
2. 逐维加入线性项和二次项；只有设计矩阵秩增加 2 时才接受该维度，拒绝纯共线证据。
3. 未被接受的维度，其 trust-region 上下界都冻结到最佳安全回放动作；候选还必须是未测量过的新动作。

21 条 seed 32 严格回放训练结果：

- 激活维度：髋俯仰、膝、踝俯仰，即 `[0, 3, 4]`。
- 冻结维度：髋横滚、髋偏航、踝横滚，即 `[1, 2, 5]`。
- 各维独立取值数：`[12, 2, 2, 8, 3, 2]`。
- critic 留一法 RMSE：`0.0553`。
- replay safe anchors：`21/21`。
- 产物仍为 `SIM_ONLY`，不允许 hot-swap、自动晋级或直接输出力矩。

## 5. 踢后不后退、不抽动的恢复闭环

### 5.1 新的物理指标

每条严格轨迹新增：

- 踢后骨盆峰值速度；
- 相对触球点的最大后退距离；
- 前向速度符号反转次数；
- 速度低于 `0.10 m/s` 的稳定耗时；
- 29 关节速度 RMS 的峰值、末值和恢复期均值；
- 恢复期骨盆平均平移速度。

这些指标直接来自 MuJoCo 轨迹，不由视频像素打分。

### 5.2 平滑恢复阻尼

新增 `post_contact_damping_scale`，范围 `[1.0, 2.5]`。它在触球后先保留 `0.18 s` 学习到的随摆，再在 `0.45 s` 内用 smoothstep 平滑提高速度反馈。所有输出仍通过原 PD、硬力矩裁剪和关节边界保护，不提高执行器权限。

seed 32 的同轨迹对比：

| 指标 | 阻尼 1.0 | 阻尼 2.5 | 变化 |
|---|---:|---:|---:|
| 球门平面误差 | 0.4811 m | 0.4811 m | 不变 |
| 恢复期关节速度 RMS 均值 | 0.1579 rad/s | 0.1025 rad/s | **-35.1%** |
| 恢复期骨盆平均速度 | 0.0548 m/s | 0.0412 m/s | **-24.9%** |
| 稳定耗时 | 4.066 s | 3.426 s | **-15.7%** |
| 前向速度反转 | 6 | 6 | 不变 |
| 后退距离 | 0 m | 0 m | 不变 |
| 饱和步数 | 27 | 28 | +1 |

2.5 档在 seed 0 上也保持球路不变、无后退、6 次速度反转、3.422 s 稳定；恢复期关节速度 RMS 均值为 `0.1055 rad/s`。因此它不是只对 seed 32 的偶然补丁，但当前只有两个技能岛证据，不能声称多分布泛化。

## 9. 下一步突破路线

1. 把接触中心帧纳入条件动作，而不是继续手工固定为 252/256；动作应成为“完整本体状态 → 相位 + 六关节残差”。
2. 用完整 65 维交接状态建立技能原型记忆；只有进入已验证技能岛才执行对应动作，未知状态 fail-closed 进入再规划，而不是盲踢。
3. 对 seeds 33+ 做真正未见方案验证；若找不到接近已知技能岛的计划，应记录拒绝，而不能把恢复站稳当作射门成功。
4. 剩余误差主要是垂直不足。下一轮应学习触球点高度、足端垂直速度和接触法向，而不是继续堆大关节残差；`±4` 帧即可导致性能坍塌，必须显式建模相位不确定性。
5. 把恢复期关节/骨盆均值指标加入持续学习 reward 和晋级门，防止“球进得更准但身体更抖”的奖励投机。

本轮真正的闭环不是“又调出一条好视频”，而是完成了：失败复验 → 方案池审计 → 第二技能岛选择 → 关节/相位消融 → 支持约束学习 → 恢复控制 → 双状态复验 → 视频与严格证据。它仍未解决高目标精准命中，但已经把下一步问题从模糊的“再加强 RL”收敛为可测的本体条件动作与触球相位学习。
