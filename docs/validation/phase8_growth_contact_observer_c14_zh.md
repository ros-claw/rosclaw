# Phase 8 / C14：接触动力学观测与技能记忆闭环

日期：2026-08-08

边界：`SIM_ONLY`，CPU MuJoCo 动力学；4 张 A6000 仅用于并行实验隔离与 EGL。

结论：完成了“严格回放 → 接触数据 → 结果模型 → 技能记忆更新 → 运行时取回”的产品闭环；连续性与安全性保持，但 0.16 m 严格射门精度仍未通过。

## 1. 为什么做这一轮

C13 已能按跑动交接全状态取回局部技能，但学习记录只有“某个动作成功/失败”，没有解释球为什么飞成这样。C14 把足端触球速度、接触法向、接触峰值力和相对触球高度从 MuJoCo 物理接触直接写入严格证据，用它们学习球初速与技能合格概率。

这不是端到端小脑，也不直接输出关节力矩。它先补齐 Growth 所缺的接触因果观测层，为下一轮反向选择触球状态、再训练动作策略提供数据基础。

## 2. 代码实现

- `unitree_mujoco_backend.py`
  - 读取最强足—球接触；
  - 将 MuJoCo 接触坐标系中的法向和接触力转换到世界坐标系；
  - 无论 ball 是 `geom1` 还是 `geom2`，统一归一成“足端指向球”的方向。
- `g1_free_kick_showcase.py`
  - 证据增加首次触球足端位置、速度、法向、世界系接触力和全程峰值力；
  - 轨迹增加逐帧足端速度、接触法向、世界系接触力与峰值力；
  - 增加 `contact_dynamics_observed_from_physics` 证据声明；
  - 技能记忆执行前必须匹配当前实现哈希，旧实现产生的技能不能静默复用。
- `ballistic_contact_observer.py`
  - 严格校验 evidence/trajectory 哈希、物理接触声明、Body/实现/实验上下文一致性；
  - 从 8 维触球状态学习三维球初速和技能合格概率；
  - 同时执行普通留一法与按 planner seed 整组留出，防止同 seed 近邻样本造成虚假泛化；
  - 明确硬顶：后触球诊断、无电机权限、无在线热切换、无硬件/晋升授权。
- CLI：`rosclaw growth ballistic-contact-observer`。

## 3. 数据闭环

采集了 14 条严格回放，覆盖 6 个不同 planner seed：

- 合格样本 9 条，拒绝样本 5 条；
- 所有样本都要求真实足—球接触、有限状态和轨迹哈希绑定；
- 动作扰动包含接触帧和髋关节 pitch 残差；
- 目标固定为 5 m 外球门左上区域 `(x=6.0, y=1.0, z=1.35)`；
- 物理仍由 CPU MuJoCo 计算，不宣称 4 GPU 物理加速。

## 4. 技能记忆更新与闭环回放

模型观测到 seed-0 附近髋 pitch 残差的小范围变化会连续改变接触力和球初速；更大的变化则会让落点迅速恶化。严格实验选择 `-0.0218 rad` 候选替换原 `-0.015 rad` 技能，并重新生成完整状态支持域记忆：

- artifact：`/code/rosclaw/phase8_evidence/g1-growth-c14-ballistic-skill-memory-v3.json`
- memory hash：`sha256:8c3198502c8085c51ae0fc1539a08f2422c41c2e6518179eb3973dabfcf04593`
- 最近拒绝状态距离：`0.7161`，大于 `0.35` 支持半径；

- 技能记忆、实现哈希和物理接触声明均在运行时实际执行。

## 5. 当前认识与下一步

本轮真正的进展是把“动作补丁”变成了可验证的数据链，而不是把 1 cm 改善包装成突破。下一步应当：

1. 增加独立 planner seed 和触球状态覆盖，采用按 seed/初始扰动分组的 sealed holdout；
2. 学习“期望球初速 → 足端触球状态 → 支持域内动作”的两级逆模型，而不是继续单参数扫描；
3. 将落点误差、触球后稳定时间和关节饱和共同作为多目标 critic，禁止为了精度牺牲平衡；
4. 只有 frozen holdout 明显降低 0.405 m 误差后，才把候选写入新的技能记忆；
5. 在始终保留 PD/力矩投影和 OOD abstention 的前提下，再评估小规模 residual actor-critic。

原始轨迹、模型和回放证据全部保留在 `/code/rosclaw/phase8_evidence`，未纳入 Git 仓库。
