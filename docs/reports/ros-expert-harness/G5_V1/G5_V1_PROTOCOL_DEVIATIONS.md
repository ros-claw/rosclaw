# G5 v1 protocol deviations and limits

- Fixed: requested model route gpt-6.1-sol, CLI 0.162.1 binary hash, medium effort, provider-default sampling policy, all arm budgets, 54 paired case/seed/arm cells, SDK image, actual source tree, training records, randomized allocation and canonical physical exit.
- Not exposed by the provider client: hidden server model revision, numeric sampling temperature and monetary cost. These are UNKNOWN; identical requested route/default policy does not prove identical hidden backend revision. The original YAML requested these pins, so this is a disclosed unresolved control limitation, not silently completed.
- Host tool-disabled read-only process isolation was used after container networking probes failed. This is not container isolation; original failed probes remain retained.
- The 300-second wall included initial capture. Actual capture and enclosing model/tool/overall clocks exist; isolated model/tool/World duration clocks do not. Timing decomposition beyond those observations is UNKNOWN.
- 48,000 prompt bytes and 12 external operations proved limiting. JSON-encoded string arguments, oversized-result file handoffs and mandatory C queries are original protocol behavior, not post-hoc exclusions.
- C excluded same-case answers and all existing J100 onboarding training. This tests restricted cross-case mechanism access and can limit measured Memory utility; it does not test unrestricted retrieval or all Memory designs.
- Misdiagnosis count is not reconstructed from free text or failed SDK startup. Static proposal acceptance and explicit parameter rejection are separately measured.
- A is not the native complete Codex product. No product-level superiority or zero-shot/hardware claim follows.
- Six case clusters and three seeds are exploratory, not a power calculation. Equal-zero observations/bootstrap intervals do not establish equivalence.
- Original 54 results, raw model events, usage and World evidence stay unchanged. Follow-up diagnostics and replay are separate artifacts. Negative/unsubstantiated findings may close this study after public seal and normal source/main delivery review; expert benefit remains unproven.
