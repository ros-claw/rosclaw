# RK05 conditional cross-Body TF mechanism transfer

This separate protocol leaves the frozen G5 corpus, experiments and same-Body
Memory admission unchanged. It transfers the abstract disabled-localization-TF
concept. It does not transfer geometry, numeric parameters, historical Body,
L1, authority or task success.

`engineering/mechanism_transfer.py` checks the current case and snapshot hashes,
current original geometry, the current TF violation, fresh disabled-broadcast
parameter readback and unique ACTIVE localization lifecycle. A competing edge,
inactive localization or contradictory broadcast readback prevents the proposal.
The current repair compiler resolves the current interfaces and minimal change.
Its output remains conditional staging with new-World proof obligations.

`benchmarks/ros_expert_ablation/cross_body_memory.py` uses the existing Memory
interface with a separately frozen TF allowlist. Exact historical record payloads,
all original proof SHA references and the pinned public archive are rechecked
before context insertion and selection. Same physical source, evaluation-episode
SHA and evaluation-World overlap are excluded. This new experiment intentionally
permits an abstract same-mechanism lesson across different physical sources; it
does not alter the older G5 same-case exclusion policy.

Retrieval, context insertion and conditional selection produce separate hashed
trace events. Model context omits historical numeric parameters. Every event
explicitly says causal benefit is NOT_ESTABLISHED. Conditional selection says
physical outcome is NOT_VERIFIED. Actual model use, independent new-Body
Before/After/Rollback, a wrong-cause counterexample and a physical outcome audit
remain required. No current trace proves Memory improved a decision or task.

The initial 30 focused tests include 13 new synthetic transfer/retrieval tests
and existing mechanism-memory regression. Fixture proof files and synthetic
archives validate contracts only; they are not real measured three-World proof.
No ROS, World, model call or physical action occurs in these tests.
