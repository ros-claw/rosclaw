# Typed application proposals from driver-only originals

`ApplicationPhysicalACI` composes the existing RSK facade and Core
`compile_driver_bootstrap`. The model supplies only the current case hash for
`ros_engineer.propose_application_bootstrap`; the host pins the original graph,
URDF, driver bringup, installed manifests, software template, explicit request
and four original application files. Missing driver/dependency observations
retain their Core abstention status and register no partial files.

The proposal contains the exact four compiler-emitted file strings and hashes,
explicit whole-file changes, original rollback strings, input semantic/byte
hashes and planned interface names. Planned interfaces are not observed
interfaces, Body admission or current L1. Input JSON ordering is retained because
serialization order affects emitted YAML/JSON bytes. Existing five-mechanism
repair materialization is unchanged; application validation uses its separate,
explicit four-file path.

The optional context projection advertises this application tool and its input
binding without compiling a solution before a model decision. The existing
bounded episode client can select it and then explicitly validate or finish.
The projection is covered by the current-state content hash. Old G5 remains
unchanged; there is no new Runtime, ROS client, driver or executor.

An injected application validator must pass the same original pilot entry gate,
operator source/run binding and shared one-validation-World counter. It receives
exact compiled files and planned interfaces for the existing owned SDK; all
physical work remains MCP→rosclawd with fresh Body/L1, source, stop, contact and
canonical receipt checks. A missing callback leaves the proposal unexecuted.
Callback failure consumes the single request budget without retry. Incomplete,
wrong-source, original-World or reused-probe-World results cannot become accepted
verification records. Real model episodes retain the existing real-clock rule;
synthetic episode clients cannot invoke these callbacks.

The new RSK callback gate also requires the SDK/probe operator source to match
the frozen harness. Generic repair validation rejects reusing a read-only probe
World. These checks affect the separate RSK facade, not frozen G5 experiments.

Unit tests and original-file proposal smokes are contract evidence only. No
model autonomy, physical completion, full 25-episode pilot or causal Memory
benefit follows from a compiled application or synthetic callback. New A/D
orchestration and independently frozen case/provider registration remain
required before a real paired study.
