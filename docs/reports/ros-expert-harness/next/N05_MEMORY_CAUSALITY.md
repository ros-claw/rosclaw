## Close the separate host-operation route

Review of the real Native tool surface found that `process_start/status/output/stop` and `stop_operation` route through the bridge to host agentd. Container-only file/shell confinement does not constrain that host process route. Opt-in historical Memory experiments now refuse canonical `HOST_PROCESS` effects and host process status/output before task admission, operation access or downstream dispatch. Generic observe/compute/execute entries use the existing canonical EffectResolver, so renaming the entry does not bypass the restriction. M0/M1/M2 receive the same restriction, malformed configured interventions also refuse, and normal profiles preserve their existing behavior. Read-only/compute/robot effects still require their original policies; this guard grants none of them.

Idempotent cached responses are also bound to the exact experimental declaration, tool arguments, session and mission. An old pre-experiment host reply or another tool/policy's cached result is refused without exposing its text or overwriting history. Matching replies remain idempotent. Default profiles retain their existing replay behavior.
