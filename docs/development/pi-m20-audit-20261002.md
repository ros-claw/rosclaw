# PI 1.0.0 compatibility and M20 experiment audit (2026-10-02)

The installed chat could remain in a foreground bash tool for days: a network
`git push | tail` had no explicit timeout, and cancellation killed the immediate
shell without reliably terminating its descendants. Provider watchdogs correctly
pause during tool execution, so they cannot repair a stuck shell.

Changes:

- Pin all four PI packages and overrides to 1.0.0, upstream commit
  `a13d35a742c6ef8462812a28fbe1d8c8b7431c32`. Record the npm lock digest.
  Both existing interactive patches replay and the package builds.
- Put guarded bash subprocesses in their own process group, terminate that group
  on cancellation and explicit timeout, and show progress every 15 seconds.
  Commands retain the existing no-default-timeout policy.
- Use `AgentSession.modelRuntime.getModel` in the harness adapter, preserve PI's
  `toolCallId`, distinguish assistant completion from user/tool messages, emit
  idle, and wake event consumers on close.
- Classify timeout, connection and cancellation errors with recoverable codes.
- Honor operator HTTP proxy settings in Node 24's native fetch for both chat and
  doctor probes; preserve explicit opt-out and bypass loopback by default.

Validation: TypeScript build and 243 tests pass (3 skipped); 49 targeted Python
and PTY tests pass; Practice tests: 183 pass, 9 skipped; configured mypy check:
121 source files pass. Modified Python files pass Ruff lint. Repository-wide
Ruff/format checks expose existing debt (275 findings / 610 files requiring
formatting); the four modified Python files already failed formatting at HEAD.
Do not interpret those checks as a green repository-wide lint gate.

Real provider tests use an isolated temporary credential home and the same
PI ModelRuntime/ROSClaw credential storage as production. Kimi and ChatGPT
both pass chat, tool selection, tool execution/result roundtrip, and persistence.
Without Node proxy support ChatGPT fails with `fetch failed`; enabling it
succeeds. A single short test is not a general model-quality benchmark. OAuth
refresh tokens from Codex are never rotated by the test.

M20 findings in the adjacent simulation workspace:

- MuJoCo freejoint angular velocity is local: remove a second rotation.
- Respect `recoil=False`; earlier A/B evidence did not actually disable recoil.
- Evaluate launch velocity at the muzzle site; body velocity is COM-centered.
- Apply opposite launch impulse through the articulated mass matrix rather than
  the base body's diagonal inertia. Independently test linear/angular momentum.
- Count failed pool requests, rather than hiding starvation in the denominator.
- Add bounded supervisory velocity/heading commands and a torque-based HOLD
  wheel brake. This is an additional controller around the unchanged ONNX,
  not a claim that stock-policy tracking now passes.
