Prepared native episodes must admit their output layout before starting a worker. File hashes do not attest that empty output directories survive a file-only copy. An actual four-case SOURCE launch failed at the first birth/clock receipt because the copied case directories had no `operator` directory. Those initialization failures remain operator failures, with model activity adjudicated separately.

Call `rosclaw.agentd.episode_layout.validate_episode_output_layout(case_root, outputs)` before dispatch, where `outputs` maps names to the planned clock, birth, exit and execution receipt paths. Pin an `operator/.keep` file in a transferred preparation packet. The function checks existing writable private parents, absent distinct outputs, and resolved containment. It reads metadata and creates no directories, sessions, credentials or clocks. A private case-root symlink alias is supported. The function must be called by the episode launcher; adding it to the package alone does not change existing launchers.

Preparation qualification must also execute the actual first receipt writer against a disposable staged copy and test missing-directory rejection before worker dispatch. Admission does not protect against later filesystem changes, ACL changes, storage exhaustion, escaped descendants, or hardware access. A pre-dispatch AST test alone does not qualify a later filesystem write.

Session initialization has its own independent contract. Generate and inspect recorded sessions using the installed public Pi SDK, and verify the actual session header/UUID/cwd before a resume probe. Pretty-printed multiline JSON is not a JSONL session header; a valid whole JSON document does not establish that Pi can open it. Model budgets, source provenance, actual tool results, semantic acceptance, durable operation state and captured process cleanup remain separate checks.
