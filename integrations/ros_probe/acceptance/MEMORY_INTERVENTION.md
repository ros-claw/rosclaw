# Native Memory intervention preparation

This is an opt-in offline-tested source path, not an accepted M0/M1/M2 causal
experiment. It uses the current Native Pi envelope and real Core Memory
repository. The historical ContextCompiler alone is not the Native injection
path.

Set `agent.ros_expert.memory_intervention` to a closed
`rosclaw.memory_intervention.v1` declaration. The declaration requires an
operator-reviewed source, explicit approval, mode, frozen database SHA256 and
at most ten individually reviewed admissions. Each admission binds the actual
Core Memory record digest, Body, episode and original public source file hash
to a matching MemoryEvidence row. Only curated admissions are implemented;
other evidence classes are refused rather than relabelled.

- M0 performs no reads of this declared historical Memory source.
- M1 returns typed factual codes only, with no historical repair pattern.
- M2 returns those facts and a bounded historical repair pattern.

M0 currently disables this source only. It does not establish global
Memory/KNOW/HOW isolation. M1 projection alone does not hide the underlying
repair bytes from an agent with general file access. A complete experiment
must isolate those bytes and all alternate retrieval paths before freezing
its protocol. No matched causal group has been run.

The source database is opened read-only and immutable. WAL snapshots,
symlink/path escapes, foreign Bodies, unreviewed/mutated records or sources,
free-form factual instructions and oversized complete results fail closed.
No current Body fact, safety authority or daemon action permission is granted
by this evidence. An absent declaration preserves the existing default.

The shared L5 renderer applies evidence and Body scope gates. Native context
injection renders historical Memory outside the authoritative embodied context
block with escaped delimiters. Per-envelope public injection records are
retained under `home/agentd/memory-contexts`, including empty M0 traces.
Retrieval and injection records report `referenced_in_decision=false` and
`causal_benefit=NOT_EVALUATED`.

The real `rosclaw_memory_query` dispatch uses the same gate. Actual successful
tool arguments containing an exact admitted memory reference can produce a
public `MemoryUseEvidenceV1` correspondence in the existing tool journal. The
retained envelope must precede the request, remain unexpired, match its mission,
context revision and current Body binding, and retain its original content hash.
A prose-only claim, failed tool, substring, retrieval query, stale context or
invalid source does not count. The tool audit retains a real SHA256 of its
summary even when advisory correspondence cannot be constructed.

This correspondence proves a reference in a recorded tool argument. It does
not prove the repair pattern was followed, a correct diagnosis was reached, or
that Memory improved the outcome. Subsequent canonical verification and
matched controls remain required, and their absence remains explicit.

Offline contracts use real AgentService journals, Core Memory rows and Native
envelopes, plus synthetic historical source files. Node tests check actual
context rendering. They dispatch no ROS motion or model inference and provide
no physical or causal acceptance evidence.
